# DSWP publication-safe derived data

This directory is the public analytical starting point for the primary
Dominica Sperm Whale Project dataset. It contains no raw DTAG audio, pressure,
accelerometer, magnetometer, GPS, field-log, or identifying metadata.

## Provenance

The reconstructed paths were created upstream from the restricted tag data.
The original internal workflow begins with
`notebooks/00_save_3d_reconstructions.ipynb`; the paper uses the subsequently
validated pitch-adaptive/hybrid reconstruction. The raw-to-reconstruction step
is recorded as provenance but is intentionally outside this public repository.
Private storage links and original serialized pickles are not reproduced here.

Every identifier in this directory is release-local:

- `W###`: individual;
- `D###`: deployment;
- `T###`: reconstructed dive trajectory;
- `B#####`: buzz event.

The crosswalk to original identifiers and whale names is neither included nor
generated by the public code.

## Files

### `trajectory_index.csv` and `trajectories/T###.npz`

The index has one row for each available pitch-adaptive reconstructed path.
Each NPZ contains exactly one float64 array, `xyz_m`, with shape
`(n_samples, 3)`. Horizontal coordinates are translated so the first point is
the local `(0, 0)` origin. The third coordinate is positive depth in metres.
Sampling rate, foraging-phase indices, maximum derived dive depth, and
truncation status are in the index.

Float64 is intentional. A float32 test changed a small number of samples lying
near the registered 30-degree turning threshold and did not reproduce the
reported per-dive step exponents exactly.

There are 228 released paths. Seventeen of the 245 dive rows had no available
pitch-adaptive reconstruction. The registered filters retain 209 foraging
dives from 20 individuals for the Lévy-like/MSD analysis.

### `buzz_events.csv`

One row per detected buzz (`n = 3,686`). The main buzz boundary columns are
seconds from the start of the corresponding released dive.
`deployment_buzz_start_s` is elapsed time within the anonymous deployment and
is retained solely to match buzzes to coarse recurrence-event intervals. None
of these values is an absolute date, local clock, or UTC timestamp.
The table contains:

- acoustic boundaries and ramp-up/plateau/terminal durations;
- derived click-rate and depth summaries;
- the original classifier speed (`avg_speed_3d_m_s`);
- pitch-adaptive reconstructed speed under its own explicit name;
- derived vertical and roll-rate summaries;
- post-buzz acoustic pause;
- vertical direction before and after the buzz; and
- comeback indicators.

The table deliberately does not contain A/B labels. The public pipeline
recomputes the GMM labels, including the ambiguous class, from the two
registered classifier variables.

### `buzz_clicks.csv`

Long-form detector output with event ID, click order, and click time relative
to the first click of the buzz. These are derived acoustic event times, not
audio samples. They allow plateau-definition and click-rate sensitivity checks
without releasing a waveform.

### `roll_speed_bins.csv`

Derived 2-s buzz-centred mean absolute roll rates in degrees per second. This
recreates the numerical input to the roll time-course panel without releasing
the underlying 25-Hz orientation stream.

### `deployment_summary.csv`

Pseudonymous deployment-level counts and recording duration. Dates, locations,
names, demographic fields, and social-unit metadata are excluded.

### `reconstruction_error_summary.csv`

Aggregate distance-to-vessel-GPS summaries for four reconstruction methods.
It contains no GPS fixes, coordinates, or timestamps and should be interpreted
as broad spatial agreement with the accompanying vessel rather than pointwise
whale location error.

### `comeback_trajectory_index.csv` and `comeback_trajectories/D###.npz`

The recurrence analysis operates at deployment scale because returns may span
multiple dives. These 30 compact archives contain the exact 20-s subsample used
by the result-producing comeback notebook. Each archive has only two float64
arrays: relative deployment time (`time_s`) and local reconstructed position
(`xyz_m`). They use the constant-speed reconstruction used by the manuscript
recurrence analysis; they are distinct from the selected
pitch-adaptive dive paths used by the main trajectory, straightness, and
energetic analyses.

### `comeback_manuscript_labels.csv`

This two-column table maps opaque buzz event IDs to the tactic labels used by
the manuscript comeback forest plot, allowing the reported OR 1.11 result to
be reproduced. The batch pipeline also computes the association with the
current classifier as a labelled sensitivity.

## Important analytical note

The reported GMM counts use `avg_speed_3d_m_s`, the classifier variable from
the original constant-speed reconstruction. The pitch-adaptive variable is
also released because it is the trajectory method selected for downstream
path, straightness, and energetic analyses.
